### 지도 기본 상세 플로우
1. 사용자: 검색어 "천안 마트" + 필터 입력
         ↓
2. 프론트 → 네이버 Places API: "천안 마트" 검색 (프론트엔드!)
         ↓
3. 네이버 API 응답: 천안 지역 모든 마트 정보
   [
     { name: "이마트 쌍용점", address: "...", lat: 36.8151, lng: 127.1139 },
     { name: "롯데마트 천안점", address: "...", lat: 36.8200, lng: 127.1200 },
     { name: "홈플러스 신부점", address: "...", lat: 36.8300, lng: 127.1300 }
   ]
         ↓
4. 프론트: 모든 마트에 핀 표시 (게시물 유무 상관없이!)
         ↓
5. 사용자: 핀 클릭 (예: "이마트 쌍용점")
         ↓
6. 프론트 → 백엔드: "이마트 쌍용점 (36.8151, 127.1139)의 게시물 있어?"
         GET /api/map/posts?storeName=이마트쌍용점&latitude=36.8151&longitude=127.1139
         ↓
7. 백엔드: DB에서 해당 위치의 게시물 검색
         WHERE store_name LIKE '%이마트쌍용%'
           AND latitude BETWEEN 36.8150 AND 36.8152  (오차 범위)
           AND longitude BETWEEN 127.1138 AND 127.1140
         ↓
8. 백엔드 응답:
   - 게시물 있으면: [{ id: 1, meetTime: "12:00", ... }]
   - 게시물 없으면: []
         ↓
9. 프론트: 모달 표시
   - 게시물 있으면: 게시물 목록 보여주기
   - 게시물 없으면: "이 마트에는 아직 게시물이 없습니다"
