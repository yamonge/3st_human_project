## 🏠 홈 화면
```
홈
 ├─ 상단 헤더
 │   ├─ 환영 메시지 ("안녕하세요, [닉네임]")
 │   └─ 서브 타이틀 ("My Own Chef에 어서오세요!")
 │
 ├─ 메뉴 섹션 (2x2 그리드)
 │   ├─ 🍳 냉장고 털기
 │   │   ├─ 설명: "영수증 활용"
 │   │   └─ 터치 → 영수증 인식 화면(카메라)으로 이동
 │   │
 │   ├─ 🎤 레시피 찾기
 │   │   ├─ 설명: "음성인식"
 │   │   └─ 터치 → 음성인식 화면으로 이동
 │   │
 │   ├─ 📋 레시피 게시판
 │   │   ├─ 설명: 없음
 │   │   └─ 터치 → 게시글 화면으로 이동
 │   │
 │   └─ 🛒 같이 장보기
 │       ├─ 설명: "지도 및 채팅"
 │       └─ 터치 → 지도 화면으로 이동
 │
 └─ 인기 레시피 섹션
     ├─ 섹션 타이틀 ("인기 레시피") + 더보기 버튼
     ├─ 레시피 카드 목록
     │   ├─ 순위 뱃지 (금/은 메달 아이콘)
     │   ├─ 레시피 제목
     │   ├─ 좋아요 수 (하트 + 숫자)
     │   └─ 카드 터치 → 레시피 상세보기
     │
     └─ 무한 스크롤 또는 더보기
```

**디자인 특징:**
- 카드형 UI with 그라데이션 배경
- 각 메뉴 카드: 아이콘 + 제목 + 설명 + 화살표
- 인기 레시피: 순위 뱃지 + 간단한 정보
- 하단 FAB 버튼 (중앙 고정)

**추가 필요 사항:**
- [ ] 로딩 상태 처리 (스켈레톤 UI)
- [ ] 네트워크 에러 처리 (재시도 버튼)
- [ ] 새로고침 기능 (Pull to Refresh)
- [ ] 빈 상태 처리 (인기 레시피 없을 때)
- [ ] 애니메이션 효과 (카드 진입 효과)

## 📝 게시글 화면
```
게시글
 ├─ 상단 헤더
 │   └─ 타이틀: "레시피 게시판"
 │
 ├─ 필터 칩 (상단, 가로 스크롤)
 │   ├─ 전체 (기본 선택)
 │   ├─ 조리시간
 │   └─ 재료 개수
 │   └─ ※ 필터 선택 시 하단 섹션들 모두 필터링됨
 │
 ├─ 인기 레시피 섹션 (필터 결과 반영)
 │   ├─ 섹션 타이틀: "인기 레시피"
 │   ├─ 큰 카드 (Featured) - 1개
 │   │   ├─ 레시피 이미지 (대형)
 │   │   ├─ 레시피 제목
 │   │   ├─ 간단 설명
 │   │   └─ 좋아요 아이콘 (우측 상단)
 │   │
 │   └─ 작은 카드 목록 (가로 스크롤) - 최대 10개
 │       ├─ 레시피 이미지 (썸네일)
 │       ├─ 레시피 제목
 │       └─ 좋아요 아이콘
 │
 ├─ 전체 레시피 섹션 (필터 결과 반영)
 │   ├─ 섹션 타이틀: "전체 레시피"
 │   ├─ 레시피 카드 (리스트 형태)
 │   │   ├─ 왼쪽: 레시피 이미지 (정사각형)
 │   │   ├─ 오른쪽: 레시피 정보
 │   │   │   ├─ 레시피 제목
 │   │   │   ├─ 준비 재료 (예: "소고기, 양파, 간장 외 2개")
 │   │   │   ├─ 조리 시간 / 난이도 (예: "5-10분 / 쉬움")
 │   │   │   └─ 좋아요 아이콘 (우측 상단)
 │   │   │
 │   │   └─ 카드 터치 → 상세보기 이동
 │   │
 │   └─ 무한 스크롤
 │
 └─ 레시피 상세보기 화면
     ├─ 상단 헤더
     │   ├─ 뒤로가기 버튼
     │   ├─ 레시피 제목 (예: "🍜 소고기 덮밥")
     │   ├─ 소유자 | 난이도 | 조리 시간 (예: "쉬움 | 10분")
     │   └─ 좋아요(하트) 버튼 (우측 하단)
     │
     ├─ 필요한 재료 섹션
     │   ├─ 섹션 타이틀(필요한 재료)
     │   └─ 재료 리스트
     │       ├─ 재료명: 수량 (예: "소고기: 200g")
     │       ├─ 재료명: 수량 (예: "양파: 1개")
     │       └─ 재료명: 수량 (예: "간장: 3스푼")
     │
     ├─ 조리 순서 섹션
     │   ├─ 섹션 타이틀(조리 순서)
     │   └─ 단계별 설명 (번호 매김)
     │       ├─ 1️⃣ 소고기를 얇게 썰어 준비하세요
     │       ├─ 2️⃣ 양파를 잘게 다져 줍니다
     │       ├─ 3️⃣ 양파를 잘 볶아 줍니다
     │       └─ 4️⃣ 간장으로 간을 해줍니다
     │
     ├─ 신고하기 버튼(텍스트형식) (오른쪽 하단)
     │
     └─ 스크롤 가능
```

**화면 플로우:**
1. 게시글 목록 진입 → 2. 필터 선택 (선택사항) → 3. 레시피 카드 터치
4. 레시피 상세보기 → 5. 뒤로가기로 목록 복귀

**디자인 특징:**
- 카드형 UI with 그라데이션 배경 (핑크/블루 계열)
- 필터 칩: 라운드 형태, 선택 시 배경색 변경
- 인기 레시피: 큰 이미지 카드 + 작은 썸네일 리스트
- 전체 레시피: 가로형 리스트 카드 (이미지 + 정보)
- 상세보기: 깔끔한 텍스트 기반 레이아웃

**추가 필요 사항:**
- [ ] 신고 기능
- [ ] 이미지 확대 보기
- [ ] 필터 저장 기능
- [ ] 로딩 상태 (스켈레톤 UI)
- [ ] Pull to Refresh (새로고침)
- [ ] 좋아요 토글 애니메이션
- [ ] 공유 기능
- [ ] 레시피 저장 (북마크)
- [ ] 작성자 프로필 이동

 │   │

 │   ├─ 상단 헤더

 │   │   └─ X 닫기 버튼
 │   │
 │   ├─ 중앙 영역
 │   │   ├─ 마이크 아이콘 (그라데이션 원형 배경)

     │   │   └─ 카드 터치 → 쇼츠 상세보기

**디자인 특징:**
- **파란색 (#007AFF)**: 주요 액션 버튼, 선택 상태

- **카드 UI**: 그림자 효과, 라운드 코너, 흰색 배경

## ⚠️ 예외 상황 및 에러 처리

### 네트워크 에러
- [ ] 인터넷 연결 없음 → 오프라인 안내
- [ ] 서버 점검 중 → 점검 안내 화면
- [ ] 타임아웃 → 재시도 옵션

### 권한 에러
- [ ] 카메라 권한 거부 → 설정 안내
- [ ] 위치 권한 거부 → 제한적 기능 안내
- [ ] 저장소 권한 거부 → 대체 방법 안내

### 데이터 에러
- [ ] 이미지 업로드 실패 → 재시도
- [ ] OCR 인식 실패 → 수동 입력 안내
- [ ] AI 추천 없음 → 일반 검색 안내

### 사용자 행동
- [ ] 잘못된 입력 → 유효성 검사 메시지
- [ ] 중복 요청 → 로딩 표시 및 방지
- [ ] 뒤로가기 연속 터치 → 앱 종료 확인
